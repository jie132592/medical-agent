# 企业级医疗问诊智能体
针对真实项目做的简化版
基于大模型 + LangGraph 多智能体调度构建的生产级医疗问诊应用
本项目采用大模型驱动+LangGraph 多智能体工作流架构，通过 TypedDict 实现强类型状态管理，深度集成 RAG 检索增强生成、工具调用、自动重试、熔断降级、错误恢复 等企业级特性。系统具备高可用、高稳定、易扩展特性，支持智能分诊、专业问诊、多轮对话，可直接用于生产环境部署与上线。

## 项目亮点
核心特性（企业级标准）
  多智能体协同调度：基于 LangGraph 实现智能体流程编排，支持分诊、问诊、检索多节点协同
  强类型状态管理：使用 TypedDict 构建类型安全状态，提升代码可维护性与稳定性
  RAG 检索增强生成：接入医疗知识库，提供专业、准确、可溯源的问诊回答
  工具调用能力：支持科室查询、症状分析、风险提示等扩展工具
  生产级稳定性：内置自动重试、熔断降级、错误恢复、异常捕获机制
  高可用架构：模块化设计、低耦合、易扩展、易维护
  多轮对话记忆：支持上下文感知，实现自然连贯的专业问诊流程
  本地私有化部署：支持 Ollama / 本地大模型，数据不出内网，安全合规


## 技术栈
  核心框架：LangGraph + LangChain
  大模型：支持本地 Ollama / 云端大模型
  工作流：多智能体调度、状态管理、流程控制
  状态管理：TypedDict 强类型安全状态
  增强能力：RAG 检索、工具调用、重试、熔断、降级
  交互界面：Gradio WebUI
  部署环境：可直接上线生产环境
